activate Pharmacist #7ACFF5
Pharmacist -> DailyInvoiceListPage: Click "Trả hàng" action button on invoice row

DailyInvoiceListPage -> InvoiceController: GET /api/v1/sales-invoices/{id} (Bearer AT)
activate InvoiceController #7ACFF5

InvoiceController -> InvoiceServiceImpl: getInvoiceByCodeOrId(invoiceId)
activate InvoiceServiceImpl #7ACFF5

activate SalesReturnModal #7ACFF5

Pharmacist -> SalesReturnModal: Check items to return, adjust return quantities, select refund method, input reason

SalesReturnModal -> InvoiceController: POST /api/v1/sales-invoices/return (SalesReturnRequest, Bearer AT)
activate InvoiceController #7ACFF5

InvoiceController -> InvoiceServiceImpl: returnSalesInvoice(SalesReturnRequest, accountId)
activate InvoiceServiceImpl #7ACFF5

InvoiceServiceImpl -> InvoiceRepository: findById(invoiceId)
activate InvoiceRepository #7ACFF5
InvoiceRepository --> InvoiceServiceImpl: SalesInvoice entity
deactivate InvoiceRepository

InvoiceServiceImpl -> InvoiceServiceImpl: Calculate totalRefund = SUM(returnQty * unitPrice)
InvoiceServiceImpl -> InvoiceServiceImpl: isFullReturn = (totalRefund >= invoice.finalAmount)
InvoiceServiceImpl -> InvoiceServiceImpl: returnType = isFullReturn ? 1 : 2 (1=FULL, 2=PARTIAL)
InvoiceServiceImpl -> InvoiceServiceImpl: generateReturnCode() -> 'RET-20261108-0001'

InvoiceServiceImpl -> ReturnRepository: save(SalesReturn: code, invoiceId, shiftId, returnType, refundAmount, reason)

activate DB #7ACFF5
DB --> ReturnRepository: SalesReturn entity (non-null return_type constraint satisfied)
deactivate DB
ReturnRepository --> InvoiceServiceImpl: savedReturn
deactivate ReturnRepository

loop For each returned item (Restock inventory)
    InvoiceServiceImpl -> InvoiceDetailRepo: findById(salesInvoiceDetailId)
    activate InvoiceDetailRepo #7ACFF5
    InvoiceDetailRepo --> InvoiceServiceImpl: SalesInvoiceDetail
    deactivate InvoiceDetailRepo
    
    InvoiceServiceImpl -> InventoryRepository: findByStoreIdAndProductIdAndBatchId(...)
    activate InventoryRepository #7ACFF5
    InventoryRepository -> DB: SELECT * FROM inventories WHERE store_id=? AND product_id=? AND batch_id=?
    activate DB #7ACFF5
    DB --> InventoryRepository: Inventory entity
    deactivate DB
    InventoryRepository --> InvoiceServiceImpl: Inventory
    deactivate InventoryRepository
    
    InvoiceServiceImpl -> InventoryRepository: inv.setQuantity(inv.quantity + returnQuantity * conversionFactor)
    activate InventoryRepository #7ACFF5
    InventoryRepository -> DB: UPDATE inventories SET quantity=?, updated_at=NOW() WHERE id=?
    activate DB #7ACFF5
    DB --> InventoryRepository: OK
    deactivate DB
    InventoryRepository --> InvoiceServiceImpl: OK
    deactivate InventoryRepository
    
    InvoiceServiceImpl -> ReturnDetailRepo: save(SalesReturnDetail)
    activate ReturnDetailRepo #7ACFF5
    ReturnDetailRepo -> DB: INSERT INTO sales_return_details (...)
    activate DB #7ACFF5
    DB --> ReturnDetailRepo: OK
    deactivate DB
    ReturnDetailRepo --> InvoiceServiceImpl: OK
    deactivate ReturnDetailRepo
end

InvoiceServiceImpl -> InvoiceRepository: invoice.setStatus(isFullReturn ? 4 : 3) -- 4=FULLY_RETURNED, 3=PARTIALLY_RETURNED
activate InvoiceRepository #7ACFF5
InvoiceRepository -> DB: UPDATE sales_invoices SET status=?, cancel_reason=? WHERE id=?
activate DB #7ACFF5
DB --> InvoiceRepository: OK
deactivate DB
InvoiceRepository --> InvoiceServiceImpl: OK
deactivate InvoiceRepository

InvoiceServiceImpl --> InvoiceController: SalesReturnResponse (returnCode, refundAmount)
deactivate InvoiceServiceImpl

deactivate InvoiceController

SalesReturnModal -> DailyInvoiceListPage: Close modal, refresh invoice table status
