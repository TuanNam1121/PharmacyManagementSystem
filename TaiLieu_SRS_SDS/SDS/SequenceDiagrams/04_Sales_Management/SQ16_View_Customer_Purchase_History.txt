Pharmacist -> DailyInvoiceListPage: Navigate to "Hóa Đơn Bán Lẻ Trong Ngày" tab

DailySalesController -> DailySalesServiceImpl: getDailyInvoices(storeId, today, pageable)

activate InvoiceRepository #7ACFF5

deactivate DailySalesController

DailyInvoiceListPage --> Pharmacist: Render invoice table with Action buttons: "Chi tiết" & "Trả hàng"

== Flow 2: Live Search by Invoice Code, Customer Name, or Phone ==
Pharmacist -> DailyInvoiceListPage: Type "3910" or "Lê Hoàng Long" into search bar
DailyInvoiceListPage -> DailyInvoiceListPage: Execute real-time client filter (codeMatch, nameMatch, phoneMatch)
DailyInvoiceListPage --> Pharmacist: Instant update table view matching search query

== Flow 3: Look Up Customer Past Purchase History at POS (F7) ==
Pharmacist -> CustomerHistoryDrawer: Click "Lịch sử mua hàng (F7)" for active customer (ID=101)
activate CustomerHistoryDrawer #7ACFF5

CustomerHistoryDrawer -> InvoiceController: GET /api/v1/sales-invoices/customer/101 (Bearer AT)

InvoiceRepository -> DB: SELECT * FROM sales_invoices WHERE customer_id=101 ORDER BY created_at DESC
