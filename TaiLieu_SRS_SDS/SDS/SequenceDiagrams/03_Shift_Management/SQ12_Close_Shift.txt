== Phase 1: Retrieve Shift Revenue Summary ==
Pharmacist -> PosCounterPage: Click "Chốt ca làm việc" button
activate PosCounterPage #7ACFF5

PosCounterPage -> ShiftController: GET /api/v1/shifts/current/summary (Bearer AT)
activate ShiftController #7ACFF5

ShiftController -> ShiftServiceImpl: getCurrentShiftSummary(accountId)
activate ShiftServiceImpl #7ACFF5

ShiftServiceImpl -> ShiftRepository: findFirstByAccount_IdAndStatus(accountId, 1)
activate ShiftRepository #7ACFF5
ShiftRepository -> DB: SELECT * FROM shifts WHERE account_id=? AND status=1
activate DB #7ACFF5
DB --> ShiftRepository: Shift entity (openShift)
deactivate DB
ShiftRepository --> ShiftServiceImpl: Shift
deactivate ShiftRepository

ShiftServiceImpl -> SalesInvoiceRepo: sumCashRevenueByShiftId(shift.getId())
activate SalesInvoiceRepo #7ACFF5
SalesInvoiceRepo -> DB: SELECT SUM(p.amount) FROM payments p JOIN sales_invoices i ON p.sales_invoice_id=i.id WHERE i.shift_id=? AND p.payment_method=1
activate DB #7ACFF5
DB --> SalesInvoiceRepo: totalCashSales (e.g. 8,500,000 VND)
deactivate DB
SalesInvoiceRepo --> ShiftServiceImpl: BigDecimal
deactivate SalesInvoiceRepo

ShiftServiceImpl -> SalesInvoiceRepo: sumTransferRevenueByShiftId(shift.getId())
activate SalesInvoiceRepo #7ACFF5
SalesInvoiceRepo -> DB: SELECT SUM(p.amount) FROM payments p JOIN sales_invoices i ON p.sales_invoice_id=i.id WHERE i.shift_id=? AND p.payment_method=2
activate DB #7ACFF5
DB --> SalesInvoiceRepo: totalTransferSales (e.g. 3,200,000 VND)
deactivate DB
SalesInvoiceRepo --> ShiftServiceImpl: BigDecimal
deactivate SalesInvoiceRepo

ShiftServiceImpl -> SalesReturnRepo: sumRefundAmountByShiftId(shift.getId())
activate SalesReturnRepo #7ACFF5
SalesReturnRepo -> DB: SELECT SUM(refund_amount) FROM sales_returns WHERE shift_id=? AND refund_method=1
activate DB #7ACFF5
DB --> SalesReturnRepo: totalRefunds (e.g. 200,000 VND)
deactivate DB
SalesReturnRepo --> ShiftServiceImpl: BigDecimal
deactivate SalesReturnRepo

ShiftServiceImpl -> ShiftServiceImpl: expectedCash = openingCash + totalCashSales - totalRefunds
activate ShiftServiceImpl #7ACFF5
deactivate ShiftServiceImpl

ShiftServiceImpl --> ShiftController: ShiftSummaryResponse (openingCash, cashSales, transferSales, expectedCash)
deactivate ShiftServiceImpl

ShiftController --> PosCounterPage: HTTP 200 OK + ShiftSummaryResponse
deactivate ShiftController

PosCounterPage -> CloseShiftModal: Open modal with calculated expectedCash (9,800,000 VND)
activate CloseShiftModal #7ACFF5

== Phase 2: Enter Actual Cash and Finalize Close Shift ==
Pharmacist -> CloseShiftModal: Count drawer cash, input actualCash = 9,800,000 VND, click "Xác nhận chốt ca"
CloseShiftModal -> CloseShiftModal: Calculate discrepancy = actualCash - expectedCash (0 VND)

CloseShiftModal -> ShiftController: POST /api/v1/shifts/close (CloseShiftRequest, Bearer AT)
activate ShiftController #7ACFF5

ShiftController -> ShiftServiceImpl: closeShift(CloseShiftRequest, accountId)
activate ShiftServiceImpl #7ACFF5

ShiftServiceImpl -> ShiftRepository: findFirstByAccount_IdAndStatus(accountId, 1)
activate ShiftRepository #7ACFF5
ShiftRepository --> ShiftServiceImpl: Shift entity
deactivate ShiftRepository

ShiftServiceImpl -> ShiftServiceImpl: Set closingTime=NOW(), closingCash, calculatedCash, status=2 (CLOSED)
activate ShiftServiceImpl #7ACFF5
deactivate ShiftServiceImpl

ShiftServiceImpl -> ShiftRepository: save(Shift)
activate ShiftRepository #7ACFF5
ShiftRepository -> DB: UPDATE shifts SET closing_time=NOW(), closing_cash=?, calculated_cash=?, discrepancy=0, status=2 WHERE id=?
activate DB #7ACFF5
DB --> ShiftRepository: OK
deactivate DB
ShiftRepository --> ShiftServiceImpl: OK
deactivate ShiftRepository

activate DB #7ACFF5

deactivate DB

deactivate AuditLogRepo

ShiftServiceImpl --> ShiftController: ShiftDetailResponse
deactivate ShiftServiceImpl

ShiftController --> CloseShiftModal: HTTP 200 OK + ShiftDetailResponse
deactivate ShiftController

deactivate CloseShiftModal

deactivate PosCounterPage
