@startuml SQ05_Forgot_Password
title UC05 - Forgot Password Sequence Diagram
autonumber "1:"
skinparam style strictuml
skinparam sequenceMessageAlign left
skinparam defaultFontName Arial
skinparam defaultFontSize 12

skinparam sequence {
    LifeLineBorderColor #000000
    LifeLineBackgroundColor #7ACFF5
    ParticipantBorderColor #000000
    ParticipantBackgroundColor #7ACFF5
    ParticipantFontColor #000000
    ParticipantFontSize 12
    ActorBorderColor #000000
    ActorBackgroundColor #7ACFF5
    ActorFontColor #000000
    ArrowColor #000000
    ArrowFontColor #000000
    GroupBorderColor #000000
}

actor "User" as User #7ACFF5
participant "<<boundary>>\nForgotPasswordPage" as ForgotPasswordPage #7ACFF5
participant "<<control>>\nAuthController" as AuthController #7ACFF5
participant "<<control>>\nAuthServiceImpl" as AuthServiceImpl #7ACFF5
participant "<<control>>\nJavaMailSender (SMTP)" as MailSender #7ACFF5
participant "<<control>>\nBCryptPasswordEncoder" as BCryptEncoder #7ACFF5
participant "<<entity>>\nAccountRepository" as AccountRepository #7ACFF5
participant "<<entity>>\nPasswordResetTokenRepository" as ResetTokenRepo #7ACFF5
database "<<entity>>\nSQL Server (PMS DB)" as DB #7ACFF5

== Phase 1: Request OTP Verification Code ==
activate User #7ACFF5
User -> ForgotPasswordPage: Enter registered email, click "Send Code"
activate ForgotPasswordPage #7ACFF5

ForgotPasswordPage -> AuthController: POST /api/v1/auth/forgot-password (ForgotPasswordRequest)
activate AuthController #7ACFF5

AuthController -> AuthServiceImpl: forgotPassword(email)
activate AuthServiceImpl #7ACFF5

AuthServiceImpl -> AccountRepository: findByEmail(email)
activate AccountRepository #7ACFF5
AccountRepository -> DB: SELECT * FROM accounts WHERE email=?
activate DB #7ACFF5
DB --> AccountRepository: Account entity
deactivate DB
AccountRepository --> AuthServiceImpl: Optional<Account>
deactivate AccountRepository

alt Email does not exist in system
    AuthServiceImpl --> AuthController: throw ResourceNotFoundException("Email không tồn tại")
    AuthController --> ForgotPasswordPage: HTTP 404 Not Found
    ForgotPasswordPage --> User: Display error "Không tìm thấy tài khoản với email này"
else Email exists & active
    AuthServiceImpl -> AuthServiceImpl: Generate 6-digit random OTP (e.g. 839201)
    AuthServiceImpl -> ResetTokenRepo: save(PasswordResetToken: otp, email, expiry=NOW()+15m, used=false)
    activate ResetTokenRepo #7ACFF5
    ResetTokenRepo -> DB: INSERT INTO password_reset_tokens (...)
    activate DB #7ACFF5
    DB --> ResetTokenRepo: OK
    deactivate DB
    ResetTokenRepo --> AuthServiceImpl: OK
    deactivate ResetTokenRepo

    AuthServiceImpl -> MailSender: send(SimpleMailMessage with OTP)
    activate MailSender #7ACFF5
    MailSender --> User: Send email with OTP to user's inbox
    deactivate MailSender

    AuthServiceImpl --> AuthController: void (Success)
    deactivate AuthServiceImpl

    AuthController --> ForgotPasswordPage: HTTP 200 OK ("Mã xác thực đã được gửi tới email")
    deactivate AuthController

    ForgotPasswordPage --> User: Transition to Step 2 (Input OTP & New Password)
end

== Phase 2: Confirm OTP & Reset Password ==
User -> ForgotPasswordPage: Enter OTP, newPassword, confirmPassword, click "Reset Password"
ForgotPasswordPage -> AuthController: POST /api/v1/auth/reset-password (ResetPasswordRequest)
activate AuthController #7ACFF5

AuthController -> AuthServiceImpl: resetPassword(ResetPasswordRequest)
activate AuthServiceImpl #7ACFF5

AuthServiceImpl -> ResetTokenRepo: findByTokenAndUsedFalse(otpCode)
activate ResetTokenRepo #7ACFF5
ResetTokenRepo -> DB: SELECT * FROM password_reset_tokens WHERE token=? AND used=0
activate DB #7ACFF5
DB --> ResetTokenRepo: PasswordResetToken entity
deactivate DB
ResetTokenRepo --> AuthServiceImpl: PasswordResetToken
deactivate ResetTokenRepo

alt OTP invalid or expired (> 15m)
    AuthServiceImpl --> AuthController: throw InvalidOtpException("Mã OTP không đúng hoặc đã hết hạn")
    AuthController --> ForgotPasswordPage: HTTP 400 Bad Request
    ForgotPasswordPage --> User: Display error "Mã OTP không hợp lệ hoặc đã hết hạn"
else OTP valid
    AuthServiceImpl -> BCryptEncoder: encode(request.getNewPassword())
    activate BCryptEncoder #7ACFF5
    BCryptEncoder --> AuthServiceImpl: encodedPassword
    deactivate BCryptEncoder

    AuthServiceImpl -> AccountRepository: account.setPassword(encodedPassword)
    activate AccountRepository #7ACFF5
    AccountRepository -> DB: UPDATE accounts SET password=? WHERE email=?
    activate DB #7ACFF5
    DB --> AccountRepository: OK
    deactivate DB
    AccountRepository --> AuthServiceImpl: OK
    deactivate AccountRepository

    AuthServiceImpl -> ResetTokenRepo: token.setUsed(true)
    activate ResetTokenRepo #7ACFF5
    ResetTokenRepo -> DB: UPDATE password_reset_tokens SET used=1 WHERE id=?
    activate DB #7ACFF5
    DB --> ResetTokenRepo: OK
    deactivate DB
    ResetTokenRepo --> AuthServiceImpl: OK
    deactivate ResetTokenRepo

    AuthServiceImpl --> AuthController: void (Success)
    deactivate AuthServiceImpl

    AuthController --> ForgotPasswordPage: HTTP 200 OK ("Đặt lại mật khẩu thành công")
    deactivate AuthController

    ForgotPasswordPage --> User: Display Toast success message and redirect to /login
end

deactivate ForgotPasswordPage
deactivate User
@enduml
